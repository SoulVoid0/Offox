This website lives in a folder on your disk. Open that folder (Offox settings → your site → Show folder) and edit index.html, style.css and script.js with any text editor, then reload this page.

Offox site API

Pages of this site can read and write files in its folder with /__offox/offox.js:

await Offox.writeText("notes/hello.txt", "Hi!");
let text = await Offox.readText("notes/hello.txt");
let files = await Offox.list("notes");
