# Editing help

Articles are written in **Markdown**, a simple way to format text.

## Formatting

| You type | You get |
|---|---|
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `~~struck~~` | ~~struck~~ |
| `` `code` `` | `code` |
| `## Heading` | a section heading |
| `- item` | a bullet list |
| `1. item` | a numbered list |
| `> quote` | a quotation |
| `---` | a horizontal line |

## Links

- Link to another article with double square brackets: `[[Offox]]` → [[Offox]].
- Show different text with a bar: `[[Offox|the browser]]` → [[Offox|the browser]].
- Links to articles that don't exist yet are red, like [[A page nobody wrote]]. Click one to create it.
- Link to another website: `[FireLine](https://fireline.offox/)` → [FireLine](https://fireline.offox/).

## Pictures

Use the 🖼 button in the editor, or upload on the **Upload file** page and paste the code it shows, e.g. `![A cat](/media/cat.jpg)`.

## Tables

```
| Name | Value |
|---|---|
| One | 1 |
```

Articles with three or more sections get a table of contents automatically.
