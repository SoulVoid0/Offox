Welcome to Offox

Offox never goes on the internet. Your websites live in folders on this computer or on an external drive. Choose a storage folder to begin; Offox will create a few websites in it to start you off: a video site at youtube.com, an encyclopedia at wikipedia.org, a notes board at reddit.com, a software store and Docs, Sheets and Slides.

Storage folders

Each website is a folder inside one of these. If two folders contain a website with the same address, the one higher in the list wins.

    Websites

    Search all of them with FireLine.

    Create a website

    Pick a template. Every website is plain HTML, CSS and JavaScript in its own folder, so you can change anything afterwards with any editor.

    Video formats

    Offox plays MP4 (H.264, H.265/HEVC, AV1), WebM (VP8, VP9, AV1), Matroska (MKV), Ogg, MP3, AAC, FLAC, Opus and WAV directly. Other formats (AVI, WMV, FLV, MPEG, MOV with old codecs, 3GP, DivX/Xvid, MPEG-TS…) are converted with FFmpeg when you upload them: the picture and sound are copied without loss when possible and re-encoded otherwise.
